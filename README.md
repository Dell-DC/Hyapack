# HYAPACK

Sustainable modular protective packaging built from harvested water hyacinth fibre blocks. React + Vite site with two pages: the landing page (`/`) and the [Multi-Use Guide](/multi-use-guide) (`/multi-use-guide`).

See [PRODUCT.md](./PRODUCT.md) for product context and [DESIGN.md](./DESIGN.md) for the visual system.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
